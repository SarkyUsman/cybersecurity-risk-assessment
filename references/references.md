Project References

1. References

The following authoritative resources were used to support the cybersecurity concepts, risk-management approach, and security controls discussed in this project.

NIST Cybersecurity Framework

National Institute of Standards and Technology (NIST).

The NIST Cybersecurity Framework provides guidance for managing and reducing cybersecurity risk.

Resource: NIST Cybersecurity Framework (CSF) 2.0

---

NIST Risk Management Framework

National Institute of Standards and Technology (NIST).

The Risk Management Framework provides a structured approach for identifying, assessing, responding to, and monitoring security and privacy risks.

Resource: NIST Risk Management Framework (RMF)

---

Cybersecurity and Infrastructure Security Agency

Cybersecurity and Infrastructure Security Agency (CISA).

CISA provides cybersecurity guidance and resources covering areas such as phishing, ransomware, vulnerability management, and cybersecurity best practices.

---

OWASP

Open Worldwide Application Security Project (OWASP).

OWASP provides freely available resources covering application security and common cybersecurity risks.

---

Center for Internet Security

Center for Internet Security (CIS).

CIS provides cybersecurity best practices and security controls designed to help organizations improve their security posture.

---

3. Project Disclaimer

GreenCare Community Hospital is a fictional organization created solely for educational and portfolio purposes.

All assets, threats, vulnerabilities, risks, and organizational details used in this project are hypothetical.

No real organization's systems were scanned, accessed, exploited, or tested during this assessment.

The recommendations presented in this project are educational and should not be treated as a formal security assessment of a real healthcare organization.

---

4. Research Integrity

This project uses publicly available cybersecurity resources for educational purposes.

The assessment findings were developed as a simulated scenario to demonstrate the process of identifying assets, threats, vulnerabilities, risks, security controls, and remediation priorities.
