# Screenshot Evidence

## Purpose

This directory is reserved for screenshots and visual evidence collected during practical cybersecurity assessments.

For this project, no screenshots of real systems are included because GreenCare Community Hospital is a fictional organization and no real systems, networks, accounts, or infrastructure were accessed or tested.

## Evidence Policy

Any screenshots added to this directory in future practical projects should:

- Clearly identify what is being demonstrated.
- Avoid exposing passwords, tokens, API keys, personal information, or other sensitive data.
- Be collected only from systems that are owned by the author or where explicit authorization has been provided.
- Include sufficient context to explain what the screenshot demonstrates.
- Never be presented as evidence from a real environment when it is simulated or lab-generated.

## Evidence Integrity

This project follows a strict evidence-integrity principle:

> Evidence must accurately represent what was actually performed.

No screenshot, scan result, system output, or security finding should be fabricated or presented as real when it was not actually obtained.
