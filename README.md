Cybersecurity Risk Assessment – GreenCare Community Hospital

A practical cybersecurity risk assessment of a fictional healthcare organization, demonstrating asset identification, threat and vulnerability analysis, risk evaluation, security controls, and remediation planning.

**Educational Project:** GreenCare Community Hospital is fictional. This project is created for cybersecurity learning and portfolio demonstration purposes.

Objectives

• Identify critical assets, threats, vulnerabilities, and security gaps.
• Assess likelihood, impact, and overall cybersecurity risk.
• Recommend appropriate security controls and risk treatments.
• Develop a prioritized remediation approach.

Methodology

The assessment uses a structured risk-analysis approach informed by NIST SP 800-30 and the NIST Cybersecurity Framework (CSF) 2.0.
**Risk Score = Likelihood × Impact**
